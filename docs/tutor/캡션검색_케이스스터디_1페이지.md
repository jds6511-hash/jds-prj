# 캡션 설명 차이가 검색 결과로 전달되는가 — 케이스 스터디 (2026-08-26)

**한 문장.** 같은 장면을 두 모델이 설명할 때 **어떤 정보를 골라 쓰느냐가 달랐고,
그 차이가 실제 검색 순위까지 전달되는 것을 확인했다. 다만 어느 한 모델이 항상
유리하지는 않았다.**

```
영상    32분짜리 요리·일상 브이로그 1편 · 5초씩 395구간
방법    시간 5등분해 장면 5개를 프레임만 보고 고르고, 장면당 질의 3개(사물·행동·맥락)를
        캡션과 검색 결과를 보기 전에 작성·동결했다. 총 15질의.
대조    같은 프레임·같은 노트북·같은 프롬프트·같은 4bit 조건에서 캡션 모델만 3B ↔ 4B
검색    캡션만 사용(자막 채널 끔) · 후보 395구간 전체
```

## 1. 대표 사례 — 같은 화면, 다른 선택, 1위가 뒤집힘 (scene02)

매장을 위에서 내려다본 **같은 프레임 한 장**을 두 모델에게 설명시켰다.

| | 캡션에 담긴 것 |
|---|---|
| **3B** | 화면의 **배너 문구**를 중심으로 — "'COSTCO'와 함께 한국어로 된 메시지", "'Join Now!'", 트럭 이미지 |
| **4B** | **냉장 진열대**를 중심으로 — "코스트코 내부의 냉장고 진열대와 주변 상품들" |

| 같은 장면을 겨냥한 검색어 | 3B | 4B |
|---|---|---|
| "대형 마트 안에 걸린 파란 광고 배너" | **1위** | 15위 |
| "냉장 진열장과 쌓인 상자가 있는 창고형 매장 내부" | 18위 | **1위** |

**모델이 화면을 맞게 보느냐 틀리게 보느냐보다, 같은 화면에서 무엇을 캡션에 남겼는지가
검색 결과에 직접 영향을 줬다.**

> 부수 관측 — 3B가 배너 글자를 그대로 옮겨 적은 것은 **프롬프트 문구 기준으로는 금지된
> 동작**이다. 다만 COSTCO 배너는 프레임 확인 결과 **매장 벽면에 실제로 부착된 배너**이고,
> 의도한 기준은 *영상 위에 덧씌운 편집 자막만 제외 · 장면 속 실제 간판 · 배너는 허용*이었다.
> **문구와 의도가 어긋나는 지점이며 별도 확인 대상이다**(프롬프트 · 인덱스는 변경하지 않았다).
> scene01의 *"이대로 기름에 튀기듯 구워주면 끝!"* 은 화면 하단 고정 · 번역 병기로
> **편집 자막(overlay)임이 확인**됐다 — 배너 사례와 같은 종류로 묶지 않는다.

## 2. 정답이 아니라 다른 장면이 1위가 됐을 때 (scene01)

정답 장면(0:00~0:05)은 **프라이팬에 기름이 차 있고 새우를 튀기는** 화면이다.

```
3B가 그 장면에 쓴 캡션
  "노란색 그릇에 담긴 노란색 소스가 보입니다. 그릇 위에는 작은 크림 요리가…"
  → 팬 · 기름 · 새우 · 튀기다 가 하나도 없다

대신 1위가 된 장면 (15:40)
  "두 개의 새우가 보입니다 … '이대로 기름에 튀기듯 구워주면 끝!'"
  → 검색어의 "새우" · "기름에 튀기"와 직접 겹친다
```

**정답을 못 찾은 이유를 "검색 실패"로 끝내지 않고, 정답 캡션에서 무엇이 빠졌고 오답
1위 캡션에는 무엇이 있었는지까지 추적할 수 있었다.**

같은 유형이 scene05에서도 나왔다 — 3B가 재봉틀 작업대를 **"배경에는 수영장이 보이며"**로
적어 세 질의 모두 148~181위로 밀렸다.

## 3. 타율 차이는 어디서 나는가

이번 5개 장면에서는 **한 모델이 항상 더 좋은 것이 아니라, 행동·사물·문자·배경 중
무엇을 캡션에 남겼는지에 따라 유리한 검색어가 달라졌다.**

```
정답 정보를 생략하면          순위가 내려간다        scene01 · scene05
다른 장면 캡션이 검색어와
더 직접적인 표현을 가지면      오답이 올라간다        scene01 · scene04
짧아서 배경어가 없으면         맥락 검색어에 불리      scene03 "주방 조리대에서…" 4B 170위
길다고 유리하지도 않다         오인이 섞이면 더 나쁨    scene05 3B가 더 길지만 181위
```

## 4. 숫자 — 보여주되 과장하지 않는다

```
Top-1 적중            3B 2/15        4B 2/15        같다
정답 순위가 더 높았던 질의  3B 4/15        4B 11/15
정답 순위 중위수        3B 31위        4B 10위
평균 캡션 길이          3B 128.5자      4B 76.4자
```

> **Top-1만 보면 둘 다 2/15로 같다. 이 사례만으로 어느 모델이 우월하다고 말할 수 없다.**
> 다만 정답의 순위를 비교하면 15개 중 11개에서 4B 쪽이 더 높았고 중위수도 31위 대
> 10위였다. **이 수치는 한 영상의 15개 질의에 대한 설명용 관찰일 뿐 일반 성능
> 추정치가 아니다.**

## 5. 이 자료로 말할 수 있는 것 / 없는 것

```
말할 수 있다   캡션이 무엇을 선택해 묘사하느냐가 검색 순위에 전달된다
              정답을 못 찾았을 때 그 원인을 캡션 수준까지 추적할 수 있다
              한 모델이 항상 유리하지는 않다

말할 수 없다   모델 우열 · 성능 추정 · 통계적 유의성 · 채택 근거
              (영상 1편 · 장면 5개 · 질의 15개 · 정성 사례 연구)
```

**배포는 3B 유지 · 4B는 후보이며 채택 아님 · 과학적 우열 미해결.**
이 케이스 스터디는 그 판단을 바꾸지 않는다.

한계 하나 더 — 두 모델을 오늘 같은 조건에서 새로 생성해 대조했지만, 두 실행의
저장소 상태가 완전히 같았다는 것까지는 입증하지 못했다(생성 코드·설정 경로에는
차이가 없음을 확인했다).
