## 1. 미해결 장벽 — 부호 역전

```
AI Hub 1,086질의   4B − 3B = +0.031   (4B 유리)
dev 96질의         4B − 3B = −0.090   (3B 유리)
```

배제된 설명 — 양자화(bf16에서도 −0.0994), 이상치(음수 47건·LOVO 불변), dev 내부
parity, 모델 revision·프롬프트 해시(두 표본 동일), 융합(α 0.0~0.9 전 구간 3B 우세).

P1(후보 풀 크기)은 **plausible contributor까지만** 닫혔다 — 양방향 `I_pool < 0`이지만
어느 표본도 자기 부호를 뒤집지 못했고 잔차 ≈0.067이 미설명이다. 그래서 P2가 병목이다.
