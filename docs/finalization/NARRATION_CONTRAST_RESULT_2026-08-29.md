```

```

**5초 조각화가 텍스트가 풍부한 영상에서 되돌아왔다.** v1에서 자유 생성으로 생겼던
문제(1구간 사건 29건)와 같은 양상이 v2 경계 선택 계약에서도 재현됐다 — 다만 원인이
다르다.

```
v1    자유 생성 계약이라 캡션마다 사건을 만들었다
geoje 경계 선택 계약인데도, **자막이 구간마다 바뀌면 모델이 그것을 상태 변화로 읽는다**
```

경계 프롬프트는 "화면 설명의 표현이 달라졌다"만으로 경계를 만들지 말라고 하지만
**자막 내용 변화**는 그 금지 목록에 없다. 대화가 이어지는 동안에도 발화가 바뀌면
경계가 생긴다.

M03은 하위 36건으로 7분(20:20~27:15)을 덮는데, 그 안이 대부분 5~10초 조각이다.

## 5. 오염 전파 — 대조가 뚜렷하다

```
                              3I7            geoje
STT 오염 → 서술 전파            2건            0건
  E07 "마포구청 인터넷 방송국 홈페이지를 방문한 후"
  E15 "다음 영상에서 만나요라는 메시지를 보여주며"
외국문자 생성                  1건 (타이)      0건
채널·광고류 표현               -              1건  E56 "첫 PPL 술을 준비하고"
```

geoje의 `첫 PPL 술`은 실제 발화로 보이며 오염이 아니다(원본 자막에 URL·채널 문구
0건). 다만 **광고 고지가 사건 서술로 올라오는 것이 최종 보고서에 적절한지**는
별개 문제다.

### 5-1. 내 파서 결함 2건 (모델 탓이 아니다)

```
E13  "여성은 바다에서 물건을 잡기 위해 노력하다"      ← 잘림
E47  "여성은 펌프를 들고 바다"                      ← 잘림
```

`parse_narration`의 첫 문장 추출 정규식이 `^(.+?[.!?다])`인데, **`바다`의 `다`를
문장 종결어미로 오인**해 거기서 자른다. 한국어 종결어미 `-다`와 명사 말음 `다`를
구분하지 않은 것이다. 모델 출력이 아니라 코드 결함이다.

**이번에 고치지 않는다** — 두 실행의 조건을 같게 유지한다. 기록만 한다.
