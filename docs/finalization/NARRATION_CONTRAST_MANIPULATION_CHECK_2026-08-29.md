# 대조군 manipulation check — 2026-08-29

```
성격   대조축이 실제로 "텍스트 증거 풍부함"인지 확인하는 사전 점검
아님   결과를 고르는 screening · 새 지표 · 성능 판단
```

**실행 전에 한다.** 대조군을 고른 근거가 사실인지 먼저 확인하지 않으면, 결과가
나와도 무엇을 비교한 것인지 말할 수 없다.

---

## 1. 왜 했나 — softyeon 선정이 틀렸다

`softyeon_ceramics`를 "발화가 많은 대조군"으로 골랐다. **두 사람 다 확인하지
않은 가정이었다.**

```
m8c2_3I7oGwk6EaQ    구간 173 · 자막 보유  33 (19%)
softyeon_ceramics   구간 192 · 자막 보유  38 (20%)
```

패널에서 **두 번째로 자막이 적은 영상**이었다. 성공했더라도 대조가 성립하지
않았다. (softyeon은 마지막 Major 단계에서 `title_count_mismatch [3, 2]`로 무효가
났고 최종 산출물을 만들지 못했다 — 대조 가치가 없으므로 재실행하지 않는다.)

패널 전체 자막 보유율.

```
wonyi_geoje              327구간 · 315 (96%)
wonyi_gyeongju           345구간 · 329 (95%)
m8c2_cIxG7OHYMPU         328구간 · 269 (82%)
baekmansonghee_jirisan   183구간 · 148 (81%)
kbs_banff                316구간 · 240 (76%)
jissi_farm               211구간 · 138 (65%)
softyeon_ceramics        192구간 ·  38 (20%)
m8c2_3I7oGwk6EaQ         173구간 ·  33 (19%)
```

## 2. 용어 정정

이 값은 **발화량이 아니다.** subtitle/STT가 비어 있지 않은 구간의 비율이다.

```
쓴다        subtitle/STT-bearing segment 19% vs 96%
쓰지 않는다  발화 19% vs 96%
```

## 3. 점검 결과 — 대조가 예상보다 훨씬 강하다

문자열 통계만 봤다.

```
=== m8c2_3I7oGwk6EaQ    자막 보유 33 / 173 (19%)
고유 문자열      4
중복 출현        33 (100%)
평균 길이        13자
전량             "다음 영상에서 만나요."          x20
                 "마포구청 인터넷 방송국 홈페이지"  x9
                 "이 시각 세계였습니다."          x2
                 "기상캐스터 배혜지"              x2
URL/채널류 문구   9
크레딧 규칙 적중   0     (is_subtitle_credit은 "한글자막 by …" 완전일치만 잡는다)
외국문자         0

=== wonyi_geoje         자막 보유 315 / 327 (96%)
고유 문자열      312
중복 출현        6 (2%)
평균 길이        37자
예시             "탈 때 할머니분들이 이렇게 1, 2, 3, 4 줄 서서 이렇게"
                 "물고기 진짜 많다. 왔어. 소문 듣고 왔어."
                 "안녕하세요, 미나미입니다. 잘 지내세요."
URL/채널류 문구   0
외국문자         1
```

**3I7의 텍스트 증거 33건은 전부 오염이다.** 실제 발화가 하나도 없다 — 화면
워터마크, 아웃트로 자막, 그리고 다른 방송에서 흘러들어온 것으로 보이는 조각
(`이 시각 세계였습니다` · `기상캐스터 배혜지`).

## 4. 두 사례의 성격 — 이렇게 부른다

```
m8c2_3I7oGwk6EaQ
  valid dialogue STT          사실상 없음
  observed STT                오염만 존재
  따라서 narration 입력은      기능적으로 caption-dominant
  관측된 실패 양상             화면 묘사 편향 + 오염 전파

wonyi_geoje
  subtitle-bearing segments   96%
  자막 문자열                  매우 다양 (고유 312 / 315)
  명백한 URL·채널 오염          screening에서 발견되지 않음
  해석 대상                    유효 대화가 풍부할 때 서술이
                              행동·사건 중심으로 바뀌는가
```

**"STT가 원인이다"를 증명하는 실험이 아니다.** 두 영상은 내용·채널·촬영 방식도
다르다. **contrastive case study**로 둔다.

## 5. 3I7 결과가 소급 설명된다

```
E07  "마포구청 인터넷 방송국 홈페이지를 방문한 후"   ← x9 워터마크
E15  "다음 영상에서 만나요라는 메시지를 보여주며"     ← x20 아웃트로
나머지 14건                                      ← 캡션만으로 서술 → 화면 묘사
```

3I7에서 관측한 화면 묘사 편향은 **caption-only 조건의 결과**였고, 자막이 쓰인 두
건은 오염을 그대로 사건으로 승격시켰다.

---

## 6. 해석은 실행 전에 고정한다

`wonyi_geoje` 결과를 세 경우로만 읽는다.

```
① 사건형 서술이 뚜렷하게 많음
   → 유효 대화 텍스트가 풍부한 사례에서 사건 중심 narration이 더 잘 나타나는
     정성적 신호가 관찰됐다

② 화면 묘사가 비슷함
   → 화면 묘사 편향은 STT availability만으로 설명되지 않으며
     narration layer 자체의 한계가 남는다

③ STT 기반 잘못된 서술·오염이 새로 많이 나타남
   → 텍스트 양보다 상류 textual evidence 품질 관리가 더 중요한 prerequisite일 수 있다
```

**비율 차이를 새 성능 지표처럼 쓰지 않는다.** Atomic narration을 전부 읽고
`EVENT_LIKE / VISUAL_DESCRIPTION / NON_EVENT`로 descriptive classification만 한다.

어느 결과든 그 뒤 **세 번째 영상은 자동으로 돌리지 않는다.**

## 7. 발표에 쓸 관찰

> 하류 LLM의 '환각처럼 보이는' 문장 중 일부는 실제로 상류 STT 오염을 충실하게
> 자연어로 확장한 것이었다. 따라서 보고서 오류를 모델 생성 문제와 입력 증거 오염
> 문제로 분리해 추적해야 한다.

`마포구청 인터넷 방송국 홈페이지` 사례가 그 예다. 원본 자막에서는 반복되는 문자열
조각이라 사람이 보면 잡음으로 읽히지만, 서술 계층을 거치면 **"홈페이지를 방문한
후"라는 행동으로 문법화**되어 사건처럼 읽힌다.
