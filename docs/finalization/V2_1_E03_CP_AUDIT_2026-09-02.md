## 감사 중 드러난 사실 세 가지

### ① caption change-point provider는 **구현 자체가 없다**

```
예약된 이름   caption_text_change_point
있는 곳       src/v2_1_guards.py의 _ADOPTION regex (금지 표지)
             V2_1_ARCHITECTURE_SPEC §candidate 절 (CANDIDATE 선언)
             C0 관찰 문서 · FINAL_REPORT_SUPPLEMENT (미채택 기록)
없는 곳       src/ 어디에도 클래스·함수·등록이 없다 (AST 전수)
```

따라서 CP-002는 **"flag가 막는다"가 아니라 "실행할 것이 없다"로 성립한다.** 이 차이를
증거에 적었다 — 나중에 구현이 생기면 그때는 flag가 실제로 막아야 하고, 지금의 증거로는
그것을 보장하지 못한다.

### ② C0 probe는 LLM 경계 일치도를 **실제로 계산한다**

```
scripts/c0_boundary_signal_probe.py
  llm_boundaries()   저장된 진단 산출물에서 4 arm 경계를 읽는다
                     qwen_full · qwen_caption_only · kanana_full · kanana_caption_only
                     (+ 3I7은 bcs_qwen_caption_only)
  probe()            arm별로 median_pct_rank · on_local_peak · on_local_peak_share를 낸다
```

즉 CP-005는 **"일치도를 재지 않는다"가 아니다.** 정확한 계약은 이것이다.

```
허용   일치도를 diagnostic으로 계산·기록한다
금지   그 일치도를 provider·threshold 채택 기준으로 쓴다
현재   판정 키가 없다 — probe는 provider_score·verdict·selected를 내지 않는다
```

"안 잰다"고 적으면 거짓이므로, 증거 목록에 **잰다는 사실을 확인하는 테스트**를 먼저 넣었다.

### ③ STEP A는 사전등록 GO였는데도 채택되지 않았다

```
AARV2_STEP_A_RESULT_2026-08-28.md
  Gate A  Δ ≥ +0.15         +0.3000   PASS      (embedding 0.55 vs uniform 0.25)
  Gate B  embedding ≥ uniform ≥ 5편   7/7 PASS
  Gate C  embedding < uniform ≤ 2편   0   PASS
  STEP A  GO
```

그런데 provider는 CANDIDATE 그대로다. **통과한 게이트가 있어도 승격하지 않았다** —
비채택의 가장 강한 증거이므로 CP-004 증거에 포함했다.

두 가지를 함께 적어 둔다.

```
STEP A 신호   mean(percentile_norm(d_sub), percentile_norm(d_cap))  ← 자막 + 캡션
CP 후보 신호   caption 단독 KURE 임베딩 인접거리
→ STEP A의 GO를 caption change-point의 GO로 옮겨 읽으면 안 된다. 다른 신호다.
```

그리고 STEP A의 GT 사용은 **측정**이다.

```
사전등록   AARV2_STEP_A_PREREG_2026-08-28.md (실행 전 동결)
정규화     영상 내 채널별 percentile rank · "하이퍼파라미터 없음" 명시
K_rule     max(1, round(duration/60))      고정
tolerance  ±10초                           고정
GO_threshold Δ ≥ +0.15                     실행 전 동결
```

즉 GT로 **성능을 재기는 했지만 파라미터를 고르지는 않았다.** CP-004가 금지하는 것은
후자다.

### 부수 정리 — `abstention_tau: 0.55`는 C0 유래가 아니다

`V2_1_ARCHITECTURE_SPEC`이 change-point 후보 절에서 "임계값(`0.55` 등)을 지금 명세에
박지 않는다"고 적고, config에는 `abstention_tau: 0.55`가 있다. **값이 같아 보이지만
서로 무관하다.**

```
abstention_tau 0.55   M5 무관련 질의 경고 임계. 2026-07-13 dev 96 vs 무관 20 재캘리브레이션
C0 관찰               2026-08-30. 임계를 정하지 않았다
```

날짜가 앞서고 계층이 다르다(검색 파이프라인 M5 vs v2.1 경계). 나중에 이것을 "내장된
C0 임계"로 오독하지 않도록 검사에 allow-list로 박았다.
