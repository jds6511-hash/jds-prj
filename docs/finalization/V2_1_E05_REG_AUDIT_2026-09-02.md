```

`strict=True`이므로 TRI-005 remediation이 들어오면 XPASS가 실패로 잡힌다 — 조용히
지나갈 수 없다.

```

## §5. 감사 중 발견한 것 — 조용한 self-skip

`tests/test_v2_1_synthesis.py`의 `GLS-007`(P1) 테스트가 이렇게 되어 있었다.

```python
synthesis = _synthesis(presented)
if synthesis.source_episode_ids:
    pytest.skip("이 fixture에서 전건 실패가 재현되지 않았다")
```

fixture가 전건 실패를 재현하지 못하면 **테스트가 조용히 skip된다.** 그러면 계약이
사라진 것을 아무도 모른다 — 대장이 금지한 바로 그 형태다.

조치(테스트 전용 강화, production 변경 없음).

```python
assert synthesis.source_episode_ids == (), \
    "fixture가 전건 실패를 재현하지 못했다 — 이 계약을 잴 수 없다"
```

지금 이 fixture는 전건 실패를 재현한다(25 tests 통과 확인). 나중에 재현되지 않게
되면 skip이 아니라 **실패**로 드러난다.

이 조치로 v2.1 테스트에서 조건부 skip은 0건이 됐고, REG-002의 marker 검사가
의미를 갖게 됐다.
