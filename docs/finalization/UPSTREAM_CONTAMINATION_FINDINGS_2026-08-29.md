## 1. 핵심 관찰 — hallucination이 아니라 faithful propagation

```
E07  "남성이 산책로를 따라 걷다가 마포구청 인터넷 방송국 홈페이지를 방문한 후,
      비가 오는 숲속을 다시 걷게 된다."
```

환각처럼 보이지만 **원본 자막에 실제로 있다.**

```
자막에 "마포구청 인터넷 방송국 홈페이지"가 있는 구간
  29 · 35 · 95 · 100 · 101 · 112 · 118 · 124 · 136     (9건)
```

화면 워터마크를 STT가 전사했거나 무발화 구간 환각이다. **서술 모델은 입력에
충실했고, 오염은 상류(M3 STT)에서 왔다.**

`common.is_subtitle_credit`은 `한글자막 by …` **완전일치**만 잡는다. 이 문자열은
대상이 아니다.

### 왜 중요한가

```
영상 → STT/caption → event representation → narration → 최종 보고서
```

> **상류의 잘못된 textual evidence는 하류 LLM이 충실하게 요약할수록 더 자연스러운
> 문장으로 증폭된다.**

원본 자막에서는 반복되는 문자열 조각이라 사람이 보면 잡음으로 읽힌다. 그러나
서술 계층을 거치면 `홈페이지를 방문한 후`라는 **행동으로 문법화**되어 사건처럼
읽힌다. "LLM hallucination"과 "input contamination propagation"은 구분해야 하고,
이 사례는 후자다.

## 2. 스크립트 오염 — 두 층에서 따로 발생

### 2-1. 캡션 (상류)

```
seg#114  "...심한 톤으로 가득 차 있는 나무들이 길两边에 서 있고..."
현행 detector flag?  False
```

`common.is_corrupted_caption`은 한자·가나가 **절대 3자 이상** 또는 비율 20% 초과일
때 잡는다. `两边`은 2자라 통과한다.

```
한자·가나가 섞인 캡션 구간   1 · 39 · 48 · 77 · 114 · 135 · 139 · 155   (8건)
현행 규칙이 잡는 것          1                                          (1건)
```

`final_report_facts_2026-08-26.json`의 `caption_qc_limitation`에 기록해둔
"현행 규칙이 flag하지 않은 추가 foreign-script 후보" 한계가 **보고서 계층까지
전파된 것을 처음으로 실물로 확인**했다.

### 2-2. 서술 (하류) — 모델이 새로 만든 것

```
E08  "...빗속에서 길을เดิน하는 상황이 발생했습니다."     ← 타이 문자
원본 segments의 타이 문자   0건
```

**상류에 없다. 서술 모델이 생성했다.**

`is_corrupted_caption`은 한자·가나 범위(`[一-鿿぀-ヿ]`)만 본다 — **타이 문자는
아예 검사 대상이 아니다.** 서술 계층에도 같은 필터를 재사용했으므로 못 걸렀다.
