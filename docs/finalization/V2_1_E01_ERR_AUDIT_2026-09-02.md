## UNPROVEN 3 — 부분 증거만 있다

### ERR-006 — highlight builder failure  **UNPROVEN** (P1)

```
matrix   highlight builder failure → canonical 유지 · fallback 가능
```

있는 것.

```
test_an_unknown_episode_is_refused                 실패는 명시적이다
test_hlt_003_canonical_structure_is_unchanged      canonical 불변 — 단, 성공 경로에서만
```

없는 것.

```
builder가 실패한 뒤 canonical(PresentationInput)이 그대로인지를 재는 테스트
= "실패 후 canonical 불변"
```

분류: **evidence-gap.** `build_highlights`는 `HighlightError`를 던지기 전에 아무것도
쓰지 않고, `PresentationInput`·`PresentationEpisode`는 frozen dataclass다. 동작은
있고 그 동작을 실패 경로에서 재는 테스트가 없다.

`fallback 가능`은 C-08 renderer fallback과 **다른 문맥**이다. C-08은 표현 실패에
대한 것이고 matrix의 이 문구는 highlight builder 실패를 말한다. C-08 테스트를 억지로
붙여 닫지 않았다.

### ERR-009 — all evidence absent  **UNPROVEN** (P0)

```
matrix   all evidence absent → hallucinated event 금지
```

있는 것.

```
test_an_episode_with_no_usable_evidence_is_still_refused
S5(전 채널 공백) 구간에서 PromptError "no usable evidence"
```

없는 것.

```
S5 전 구간을 정본 → 표현 → 문서까지 태워 hallucinated event/content가
생기지 않음을 보이는 경로
```

분류: **evidence-gap.** 계층별 동작은 각각 존재한다 — 프롬프트가 거부하고, C-04는
`NO_RELIABLE_CONTENT`로 결론을 적지 않으며, C-05는 `summary=None`, C-06/C-07은
자리표시자 문장을 만들지 않는다. 그러나 **전 채널 공백 입력 하나로 그 사슬 전체를
통과시킨 테스트가 없다.** 프롬프트 거부 하나로 닫으면 "정본 구조가 있다"와
"의미적 사건이 없다"를 구분하지 못한다.
