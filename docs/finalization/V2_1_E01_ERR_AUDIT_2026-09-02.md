## E-01a-1 — ERR-006 실패 후 canonical 불변

```
test_err_006_a_builder_failure_leaves_the_canonical_untouched   [3 modes]
```

"예외를 던진다"로 닫지 않는다. **실패 전후 지문을 비교한다.**

```
지문   정본 문서 전체(JSON · sort_keys)
      episode_id · start_seg · end_seg · start_sec · end_sec · 순서 · 개수
```

세 실패 모드 전부에서 첫 spec은 정상이다 — **부분 작업이 이미 일어난 뒤** 실패해야
"실패 후 불변"이 의미를 갖는다.

```
unknown_episode    존재하지 않는 episode 참조
empty_group        빈 묶음
repeat_in_group    한 묶음 안에 같은 episode 두 번
```

부분 산출물이 남지 않는 것도 함께 본다 — 실패 후 다시 세우면 `H01`부터다(id 카운터
누적이 없다). 정본 문서가 여전히 표현 입구로 열리는 것으로 `fallback 가능`을 잡는다.
C-08 renderer fallback과 섞지 않았다.

## E-01a-2 — ERR-009 근거 전무 end-to-end

```
test_err_009_all_evidence_absent_keeps_structure_and_invents_nothing
```

S5(전 채널 공백)를 **정본에서 세 renderer까지** 태운다. 두 가지를 **동시에**
증명해야 하기 때문이다.

```
구조는 살아 있다        AND        내용은 지어내지 않는다
```

경로.

```
1  프롬프트가 전 구간을 거부한다            PromptError "no usable evidence"
   → content_status = EMPTY 가 가정이 아니라 관측이다
2  구조                                  EP01·EP02·EP03 · span (0,3)(4,7)(8,11)
                                        end_sec 20 · 40 · 60
3  내용                                  summary None · dialogue_note None
                                        표현 자격 전부 False
4  lineage                               ("EP01","EP02") · ("EP03",) 그대로 남는다
5  global synthesis                      NO_RELIABLE_CONTENT
                                        overview "" · analysis () · sources ()
                                        excluded EP01·EP02·EP03
6  highlight summary                     None · NO_RELIABLE_CONTENT
                                        summary 출처 () · 제외 = 구성 전체
7  markdown · preview · hwpx             id·시각·구성 구간은 적힌다
                                        요약 칸은 (NO_RELIABLE_CONTENT)
```

환각 검사는 전역 문자열 검색이 아니라 **문장 집합**으로 한다.

```
허용되는 평서문   "근거가 확인된 구간이 없어 결론을 적지 않는다."  (종합 결론) 뿐
markdown · hwpx  그 한 문장
preview          없음
```

자리표시자 서술이 어느 renderer에서 생기든 이 집합이 커져서 깨진다.

## E-01a-3 — ERR-010 echo peak가 경계를 밀지 못한다

```
test_err_010_an_instruction_echo_peak_does_not_move_the_fixed_window   [3 창]
```

기존 채널 무관성 검사는 S1·S3·S4·S5였고 **S6이 빠져 있었다.** S6를 넣되, 단순히
목록에 더하는 것으로 끝내지 않는다.

```
오염 신호   boundary_signal 을 echo 구간(#3)·외국어 캡션 구간(#7)에서 최대치로 준다
           값 0.6798 = 2026-08-30 C0 geoje chunk3 실측 최대 peak
창 길이     15s · 20s · 60s   (60s 단독이면 창이 하나뿐이어서 비교가 무의미하다)
비교        boundary_positions · window_spans · episode 시간 구조
```

`source`는 비교하지 않는다 — 채널 파생 field이므로 채널이 다르면 달라지는 것이
정상이고, 여기서 재는 것은 시간 구조다.

보조 증거를 같은 테스트 안에 함께 둔다.

```
SAN   그 캡션은 REJECTED · reason = instruction_echo   오염으로 인식된다
FW    그런데 경계는 격자만 따른다                        영향이 없다
```

fixture에서 echo를 빼면 이 테스트가 깨진다 — 즉 무의미해질 수 없다.
