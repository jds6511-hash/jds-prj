## 2. 왜 닫는가

사후 분석에서 **사건의 시간적 입도 자체가 평가 결과를 크게 좌우한다**는 것이
반복해서 드러났다.

```
GT 68건 길이     min 10초 · p25 30초 · median 62초 · p75 181초 · max 865초
                 86배 범위 — 단일 입도 설계로 동시에 맞추기 어렵다

C3 max 7.00      영상 1편(m8c2_3I7oGwk6EaQ, GT 1건 · 865초)이 값을 결정했다
                 어떤 분할로도 그 영상에서 임계 2.0을 만족할 수 없다

C2 임계 0.70      원 사전등록이 외부 근거가 없다고 스스로 밝힌 값이다
```

즉 낮은 점수가 "모델이 그만큼 나빴다"를 뜻하는지, "기준의 사건 단위가 그 영상에
맞지 않았다"를 뜻하는지 **분리되지 않는다.**

**그래서 그 방향으로 더 최적화하지 않는다.** 기준이 틀렸다고 선언하는 것이
아니라, 그 기준에 시스템을 맞추는 작업을 중단한다는 결정이다.

## 6. 다음 연구 질문

프로토타입 4회에서 실제로 드러난 병목은 계층이 아니라 서술이었다.

> **5초 단위 VLM 캡션을 모았을 때, 화면 묘사가 아니라 시간적으로 진행되는
> 사건 서술로 어떻게 바꾸는가.**

v3 서술은 전부 화면 묘사에 머물렀다.

```
"화면은 어두운 밤이나 아침의 풍경을 보여주며..."
"푸른 하늘, 구름, 바위, 나무, 식물들이 주를 이루며..."
"주변은 푸른색과 녹색으로 가득 차 있으며, 바람이 불면서 나뭇잎이 흔들리고 있습니다."
"푸른색 바닥과 나무, 식물들이 있는 자연 풍경이 화면에 보입니다."
```

**이 질문은 라벨 없이 실험할 수 있다.**

책임을 분리한다.

```

렌더링       코드
```

JSON·title·grouping을 한 번에 시키지 않으면 지금까지 겪은 형식 실패
(v1 자유생성 · v3 title 12/16 누락 · v4 title 보수 실패)도 크게 줄어든다.

## 8. 발표 문구 — 이대로 인용한다

> 초기 M8에서는 사람이 정의한 reference event를 이용해 정량 평가를 수행했으나,
> 후속 분석 과정에서 사건의 시간적 입도 자체가 평가 결과에 크게 영향을 줄 수
> 있다고 판단했다. 따라서 해당 reference set을 이후 모델 최적화 기준으로 사용하지
> 않고, 후속 단계에서는 시간축 무결성, 근거 추적 가능성, 실제 보고서의 사건 중심
> 서술 품질을 중심으로 탐색했다.

기존 실험을 숨기지 않고, 그 라벨을 계속 정답처럼 끌고 가지도 않는다.
