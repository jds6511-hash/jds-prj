## 2. 단변량 분해 — 신호가 어디에 없는가

| feature | 단변량 AUC | |
|---|---|---|
| `sub_top1_minus_top5` | **0.5855** | 8개 중 최고 |
| `sub_top1_score` | 0.5531 | |
| `sub_top1_minus_top2` | 0.5456 | |
| `sub_top2_score` | 0.5208 | |
| `cap_top1_score` | 0.5167 | |
| `sub_cap_top1_score_gap` | 0.5096 | |
| `cap_top1_minus_top2` | 0.4957 | **우연 수준** |
| `sub_cap_top1_same_segment` | 0.4938 | **우연 수준** |

두 가지가 보인다.

**(1) 다변량이 최고 단변량을 못 넘는다.** 8 feature 결합 0.5812 ≤ 단독 0.5855.
feature를 더한 값이 없다.

**(2) 캡션 채널·채널 합의 feature는 전부 우연 수준이다**(0.4938~0.5167). 자문에서
기대한 "자막과 캡션이 불일치하면 자막이 애매한 상태"라는 신호가 **없다.**

**해석.** 자막이 GT를 1위로 두는 상태와 2~5위로 두는 상태는 **점수 기하에서
구분되지 않는다.** 자막 top1 점수는 그 순위가 옳은지에 대한 신뢰도 프록시로
쓸 수 없다. 남은 미약한 신호(top1−top5, 즉 분포의 뾰족함)도 0.586이다.

**대안 목표변수가 더 중요하다.** "α를 내리면 이득 보는 질의"는 [2,5] 층보다
직접적인 표적인데, 그것도 CI 상한 0.667로 밴드에 못 닿는다. 사후 정의라 판정에
쓰지 않지만, **다른 표적을 잡으면 될 것**이라는 도피로를 막는다.

## 4. 이 결과가 말하는 것 / 말하지 않는 것

**말하는 것.**

- **적응 α는 이 feature 집합·이 선형 모델로는 구현 불가다.** 게이팅 신호가 없다.
- 신호 부재는 **캡션 모델 탓이 아니다**(arm 강건성).
- 표본 부족 탓도 **아니다**(AUC 0.622 이상이면 검출했다).

**말하지 않는 것.**

- 더 풍부한 feature나 비선형 모델이면 된다는 **부정은 아니다.** 사전등록이
  8 feature·로지스틱으로 못박았고, 그 밖은 재지 않았다.
- **[2,5]가 옳은 층 경계라는 확증이 아니다.** 이 경계는 전달분해 §3-3의 사후
  층화에서 왔고, 원문이 그렇게 자백한다. 이번 진단은 그 경계를 검증하지 않았다.
- 이 표본은 **재사용됐다**(모델 확증·2×2). 선택·추정으로 읽는다.
