# I1 검증셋 A단계 — 오탐은 0건, 문제는 미탐 쪽이다

사전등록 `I1검증셋_사전등록_2026-08-18.md`(`3ab4a8f`) + 보충 `B단계경계`(`8705e1b`).
라벨 116프레임 전건 완료 · 분석 `docs/probes/_scratch/i1_label_analysis.json`.
**A단계만이다 — precision·recall이라는 말은 B 뒤에만 쓴다.**

---

## 0. 결론

> **현행 I1a가 잡은 72건 중 화면에 한자·가나가 있던 프레임은 0건이다.**
> 즉 **scene text를 오염으로 오인한 사례가 이 표본에 없다.**

> **문제는 반대쪽이다.** CJK 1~2자만 흘린 캡션(모집단 800건)은 화면에 글자가 없는데도
> 현행 임계(CJK 절대 3자)가 잡지 못한다. 표본 20건 중 **19건**이 화면 글자 없음.

**이것이 순환 우려를 상당 부분 해소한다.** `4B/P0` 선호의 근거였던 I1a 적중이
**오탐으로 부풀려진 값이 아니었다.**

## 1. 전수 추정량 — I1a 적중분 (표집오차 없음)

`C1`+`C3`+`C4`+`C5` 전건. `unclear` 제외 후 **72 인스턴스**.

| | |
|---|---|
| 화면에 CJK 있음 (= scene text, **오탐 후보**) | **0** |
| 화면에 CJK 없음 (= drift 후보) | **72** |
| `precision_vs_frame_text_proxy` | **1.0** |

**이름을 지킨다.** 화면에 글자가 없으므로 scene text일 수 없다는 것까지가 A의 결론이다.
"캡션의 한자가 의미적으로 이탈했는가"는 B의 질문이고, 여기서는 답하지 않는다.

## 3. 화면 글자 기저율 — C0을 넣은 이유가 여기서 드러난다

| | |
|---|---|
| `cjk_text_present` 비율 (전 표본) | **0.0092** |
| 영상 클러스터 95% CI (61영상) | **[0.0000, 0.0308]** |

**AI Hub 프레임에 한자·가나는 사실상 없다.** 116프레임 중 1장뿐이다.
`no_text` 76 · `korean_text_only` 19 · `unclear` 20 · `cjk_text_present` **1**.

기저율이 이렇게 낮으므로, **캡션의 한자를 "화면 글자를 옮긴 것"으로 설명하기 어렵다.**
C0을 사전등록에 넣지 않았다면 이 판단을 못 했다.

## 5. B단계 — 필요 대상이 **1건**으로 줄었다

보충 사전등록의 도출 규칙표는 이렇게 정했다.

| 캡션 CJK | A 라벨 | 도출 |
|---|---|---|
| 있음 | `cjk_text_present` | **B 필요** — scene text인지 `drift_despite_text`인지 |
| 있음 | `korean_text_only`·`no_text` | **drift** (B 불요) |

A 결과에서 `cjk_text_present`는 **`S069` 하나**다. 따라서 **(가) 집합 = 1건.**

> **사전등록 문안과 도출 규칙표가 어긋난다 — 기록한다.**
> 보충 §"고정하는 경계"는 **(나) I1a 음성 표본 전부**에도 B를 필수로 적었다. 그러나
> 같은 문서의 도출 규칙표는 `no_text`면 B 없이 drift로 확정한다. 표 쪽이 더 정확하다 —
> 화면에 글자가 없으면 대응 여부를 물을 대상 자체가 없다.
> **문서를 고치지 않는다.** 실행 시 (가) 1건은 반드시 하고, (나) 중 캡션에 CJK가
> 있는 20건(C2)은 문안대로 함께 확인한다 — 21건이면 비용이 거의 없다.

## 6. 한계

- **A단계다.** `precision`·`recall`을 말하지 않았고, 산출 JSON에 `recall` 키가 없다.
- **`unclear` 16.2%**(프레임 기준 20/116). 주분석에서 제외했다. 이 비율이 낮지 않다 —
  화면 글자가 작거나 흐린 경우가 많다는 뜻이고, `cjk_text_present`를 놓쳤을 여지가 있다.
- **구간 5초에 대표 프레임 1장.** 다른 시점에만 글자가 나오면 `no_text`가 된다 —
  **drift 과대추정 방향**이다. §1의 "오탐 0건"은 이 방향의 편의를 받은 값이다.
- **C2는 800 중 20만 봤다.** 미탐률 CI가 넓다.
- 표본은 AI Hub이고 모델 선택에 이미 쓴 표본이다. 선택·추정으로 읽는다.

## 7. 이 결과가 바꾸는 것

| | |
|---|---|
| **순환 우려** | **상당 부분 해소.** I1a 적중이 scene text 오탐으로 부풀려진 값이 아니다 |
| **검출기 재설계 방향** | 오탐 억제가 아니라 **미탐 축소**가 과제다. `foreign_script_present`(≥1자)를 진단 지표로 두자는 설계안이 실측으로 지지된다 |
| **`4B/P0` vs `4B/P1`** | 이 결과만으로 확정하지 않는다. 4B가 CJK를 더 많이 쓴다는 사실(241·341 vs 125)은 그대로이고, 그것이 미탐 구간에 몰려 있다 |
| **hard gate 승격** | **아직 아니다.** B 21건 + 새 규칙 설계 + 다음 사이클 사전등록 순서를 지킨다 |
