## 2. 이 제약이 판정에 미치는 영향 — 미리 적는다

### 2-1. 대비는 대부분 C2에 있다 — 그래서 C2-only가 표적을 벗어나지 않는다

development 실측에서 세 규칙의 셀별 발동은 이랬다.

```
C4   현행 68/68 · primary 68/68 · fallback 67/68
C5   현행 3/3   · primary 3/3   · fallback 3/3
C2   현행 0/20  · primary 15/20 · fallback 15/20
```

**규칙 간 차이가 사실상 전부 C2에서 나온다.** 따라서 C2를 fresh로 재는 것은
**이번 재설계가 새로 건드리는 구역을 정확히 겨냥한다.**

### 2-2. 전체 모집단 수치는 development census를 이어받는다 — **재검증 아니다**

C4·C5·C1은 새로 잴 수 없으므로, 전체 모집단 precision·recall을 내려면 그 셀의
**development 시점 census 라벨을 그대로 이어 쓸 수밖에 없다.**

```
표기      carried_over_census: true 를 셀별로 명시한다
금지      그 셀의 수치를 "validation에서 확인됐다"고 쓰는 것
허용      "C4·C5는 전수 census를 이어받았고 이번에 재검증되지 않았다"
```

**전체 수치와 C2-only 수치를 나란히 낸다.** 둘을 섞어 하나로 보고하지 않는다.

### 2-3. **primary와 fallback은 fresh 데이터로 구분할 수 없다**

두 후보의 development 차이(`recall_est` 0.7704 vs 0.7692)의 실체는 **C4 인스턴스
1건**이었다. C4 잔여가 0이므로 **그 차이를 새 표본에서 판정하는 것이 원리상
불가능하다.**

```
따라서   두 후보가 validation 조건을 모두 만족하면
         보충1 §5의 동률 규칙(단순한 규칙 우선)에 따라 **R_only (R=2)**를 선택한다
금지     development의 0.0012 차이를 validation에서 "확인"하려 시도하는 것
금지     C4 census를 다시 꺼내 두 후보를 가르는 것 — 그 1건이 후보 선정에
         쓰인 바로 그 인스턴스다
```

### 2-4. C4·C5 구역을 fresh로 재려면 별도 사전등록이다

이 모집단(AI Hub 2×2 캡션)에는 남은 인스턴스가 없다. 재려면 **다른 캡션 모집단**
(예: `prec3_0818b` dev 3-arm 산출물)을 써야 하고, 그것은 **표집틀 변경**이므로
새 사전등록이 필요하다. **이 사이클에서는 하지 않는다.**

## 3. C0 불변식 — 반복 branch가 발동하면 자동 TN으로 처리하지 않는다

비교 대상은 CJK 규칙이 아니라 **`language_drift(CJK) OR 반복 규칙`**이다. C0에서
변경하지 않은 반복 규칙이 발동할 수 있다면, 그 인스턴스를 자동 TN처럼 취급하면
FP 회계가 사라진다.

**구조적으로는 발동할 수 없다** — C0의 정의가 `CJK 0 ∧ 현행 미적중`이고, 반복 성분은
`현행 적중 ∧ ¬CJK규칙`이므로 C0에서 거짓이다. development 실측에서도 C0 24건의
`i1a_hit`은 전부 `False`였다.

**그러나 추론으로 두지 않는다.** 불변식으로 강제한다.

```
불변식 1   C0 인스턴스에서 baseline·primary·fallback 중 어느 것도 발동하지 않는다
           하나라도 발동하면 **fail-closed** — 셀 정의와 데이터가 어긋났다는 뜻이다
불변식 2   n_fired − n_tp == FP_declared + FP_outside_declared   (모든 규칙·모든 셀)
적용       "human label 생략"은 frozen derivation rule상 ground truth가 결정되는
           경우에만 쓴다. 발동한 인스턴스는 생략 대상이 아니다
```

**불변식 1이 깨지면 C0의 human label 생략이 무효다** — 그 경우 분석을 중단하고
사용자에게 보고한다.

## 4. 재현 게이트를 validation 코드에도 유지한다

```
게이트   frozen reference estimate를 먼저 재현하지 못하면 candidate 결과를 열지 않는다
기준     현행 detector의 해당 표본 지표. 전수 이어받은 셀은 development 공표값과 일치
불일치   중단. 허용 오차를 늘리거나 게이트를 끄지 않는다
```

development에서 이 게이트가 추정량 결함 2건을 잡았고 **둘 다 대조군을 실제보다 좋게
보이게 하는 방향**이었다(전수 셀 스케일링, 대조군을 CJK 규칙만으로 세운 것).
같은 방향의 실수가 validation에서 다시 나오지 않게 게이트를 이어받는다.

## 5. Wilson 구간은 descriptive다

`C2 60`이면 `p≈0.75` 부근에서 Wilson 반폭이 ±0.11 수준이다(24에서 ±0.17).

> **폭이 좁아졌다고 정밀도가 충분하다고 선언하지 않는다.** 표본은 프레임
> 클러스터이고 같은 영상·콘텐츠 구조가 남아 있으므로 **실제 불확실성은 Wilson보다
> 넓을 수 있다.** 기존 제한을 그대로 유지한다.
