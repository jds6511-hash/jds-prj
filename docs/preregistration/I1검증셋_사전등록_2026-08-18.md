# 사전등록 — I1 검증셋 (층화 규칙·라벨 규약)

**작성 2026-08-18. 층화 규칙을 고정한 뒤 표본을 뽑는다.** 이 문서는 수정하지 않는다.

---

## 0. 이 사이클이 하는 것 / 하지 않는 것

| | |
|---|---|
| 목표 | **현행 `is_corrupted_caption`(I1a)이 실제 language drift를 얼마나 잡고 scene text를 얼마나 잘못 잡는지** 잴 수 있는 검증셋을 만든다 |
| **하지 않는 것** | **새 detector 규칙을 만들지 않는다.** 규칙을 먼저 만들고 그 규칙으로 표본을 해석하면 다시 순환이다 |
| | hard gate 승격 없음. `4B/P0` 최종 후보 확정 없음. 캡션·인덱스·α·τ 불변 |
| test 접촉 | 없음. 표본은 AI Hub `split="external"` 2×2 산출물 |

**순서를 고정한다.** 층화 규칙 사전고정 → 시트 생성 → **사용자 프레임 라벨** →
그 라벨로 I1a precision/recall·실패 유형 분석 → 그다음 새 detector 설계 →
**다음 사이클** 사전등록.

---

## 1. 왜 2단계로 나누는가

`language_drift`는 **프레임만 보고 판정할 수 없다.** 캡션의 한자가 화면 글자를
옮긴 것인지 이탈인지 보려면 캡션을 봐야 한다. 그런데 캡션을 같이 보여주면
**캡션에 적힌 글자를 화면에서 봤다고 믿는 편향**이 생긴다(캡션이 "간판에 中国이라
쓰여 있다"고 하면 흐릿한 간판이 그렇게 보인다).

| 단계 | 보이는 것 | 라벨 | 성격 |
|---|---|---|---|
| **A** | **프레임 + 시각만** | 화면에 한자/가나 글자가 있는가 | **필수·완전 블라인드** |
| **B** | 프레임 + 캡션(arm·판정 은닉) | 캡션의 외국어가 화면 글자와 대응하는가 | **선택**, A로 안 갈리는 것만 |

**A의 라벨은 arm과 무관하다** — 프레임이 4 arm에서 동일하므로 **한 번 라벨하면
4 arm 전부에 쓰인다.** 이것이 사람 시간을 4배 아낀다.

**A만으로 대부분 갈린다.**

| 캡션에 CJK | 프레임 A 라벨 | 도출 |
|---|---|---|
| 있음 | 한자/가나 있음 | **scene text 후보** — I1a가 잡았다면 오탐 후보 |
| 있음 | 한글만 / 글자 없음 | **language drift** — I1a가 놓쳤다면 미탐 |
| 없음 | 무엇이든 | I1a 적중이면 비-CJK 원인(반복) |

## 2. 층화 — 캡션 단위 셀 (사전 고정)

모집단: 2×2 4 arm × 194영상 × 12구간 = **9,312 캡션 인스턴스**
(`docs/probes/_scratch/aihub_2x2_captions/full_2026-08-17/`).

셀은 **서로 겹치지 않게** 두 축으로 정의한다.
CJK = `[一-鿿぀-ヿ]` 문자 수(현행 detector와 동일 정규식). I1a = `is_corrupted_caption`.

| 셀 | 정의 | 할당 | 왜 |
|---|---|---|---|
| **C0** | CJK 0 · I1a 미적중 | 24 | **정상 대조군.** 화면 글자 기저율을 모르면 나머지 해석이 불가능하다 |
| **C1** | CJK 0 · I1a 적중 | 전수(상한 12) | 비-CJK 원인 — 구 반복·어절 반복 |
| **C2** | CJK 1–2 · I1a 미적중 | 24 | **4B 누출 지대.** 검출기가 놓치는 곳 |
| **C3** | CJK 1–2 · I1a 적중 | 전수(상한 12) | 짧은 캡션에서 비율 규칙(>0.2)이 발동한 것 |
| **C4** | CJK 3–9 | 24 | **3B 축적 지대** |
| **C5** | CJK 10+ | 전수(상한 24) | 심각. **`4B/P0` 최장 사례(157자)는 강제 포함** |

**C0의 추가는 의도적이다.** 사용자 초안에는 없었지만, 화면에 글자가 있는 프레임의
**기저율**을 모르면 "scene text 후보"라는 판정 자체가 해석되지 않는다. AI Hub
프레임의 40%에 글자가 있다면 대응은 우연일 수 있다.

**셀 안 배분.** arm 4개에 균등 할당(`quota//4`, 부족분은 가용 arm에서 채움).
그 안에서는 `seed=config.seed` 고정 무작위. **사후에 고르지 않는다.**

**부수 지표는 셀 정의에 쓰지 않고 기록만 한다** — CJK 비율, 최장 연속 CJK run.
셀을 이것들로 더 쪼개면 셀당 표본이 라벨 불가능한 수준으로 작아진다.

## 3. 단계 A 라벨 규약 (사용자 작성)

**시트에 들어가는 것: 프레임 이미지, 시각, `sample_id`.**
**들어가지 않는 것: arm명·캡션·I1 판정·셀 이름·검색 순위·영상 제목.**
표본 순서는 셀·arm과 무관하게 무작위로 섞는다.

라벨 하나를 고른다.

```
cjk_text_present    화면에 한자 또는 가나 글자가 보인다
korean_text_only    글자는 있으나 한글(또는 로마자)만
no_text             읽을 만한 글자가 없다
unclear             흐림·가림·너무 작음 — 판단 불가
```

**규약.**
- 화면에 **실제로 보이는 것**만 센다. 추측·맥락 추론 금지.
- 애매하면 `unclear`. `unclear` 비율은 결과에 보고하고 주분석에서 제외한다.
- 라벨 도중 캡션·검색 결과를 열지 않는다(CLAUDE.md 3조와 같은 이유).

**한계를 미리 적는다.** 구간은 5초인데 대표 프레임은 한 장이다. 5초 안 다른
시점에만 글자가 나오면 `no_text`로 라벨된다. 이 방향의 오차는 **drift 과대추정**
쪽으로 작용한다 — 결과 해석에 병기한다.

## 4. 단계 A 이후 산출 (라벨 수령 후)

`unclear` 제외하고 arm별로 낸다.

| 지표 | 정의 |
|---|---|
| **I1a precision** | I1a 적중 중 drift 도출분 비율 |
| **I1a recall** | drift 도출분 중 I1a가 잡은 비율 |
| **오탐 유형** | I1a 적중 ∧ `cjk_text_present` (scene text를 오염으로 잡음) |
| **미탐 유형** | I1a 미적중 ∧ CJK 있음 ∧ 화면 글자 없음 |
| 기저율 | C0에서 `cjk_text_present` 비율 |

**셀별 추출률이 다르므로 모집단 추정에는 셀 가중을 쓴다.** 표본 비율을 그대로
모집단 비율로 읽지 않는다.

**CI는 영상 클러스터 부트스트랩**으로 낸다(같은 영상의 프레임은 상관된다).

## 5. 단계 B (선택)

A에서 `cjk_text_present`로 갈린 인스턴스만 대상. 프레임 + 캡션을 함께 보이되
**arm·I1 판정·순위는 계속 숨긴다.** 라벨:

```
matches_screen      캡션의 외국어가 화면 글자와 대응한다
drift_despite_text  화면에 글자는 있으나 캡션 외국어는 무관하다
unclear
```

**A 결과를 보고 B 실행 여부를 정한다.** A에서 오탐 후보가 거의 없으면 B는 불필요하다.
