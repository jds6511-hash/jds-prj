## 1. **집중도 — 프로그램 지표로는 안 보인다**

```
프로그램 최대 점유율   0.2564   (한국기행 10/39)
방송사 최대 점유율     0.9091   (EBS 30/33, 강연 제외 기준)
```

**프로그램별로는 고르게 퍼져 보이지만 방송사로 묶으면 EBS가 91%다.** 같은 제작
관행·자막 스타일·촬영 문법이 표본을 지배하면 **외적 타당도 문제**다. 게이트 지표에
방송사 축을 추가했다(초판은 프로그램 축만 봤다 — 그것이 내 지표 공백이었다).

## 2. inventory 필드 — 기록만 하고 선택에 쓰지 않는다

```
source          방송사·출처 (ebs · kbs · other · lecture)
family          프로그램 계열
domain          내용 범주 (여행·건축·작업현장 …)
duration_sec    yt-dlp 실측
est_segments    ceil(duration / 5)
eligible        750 <= duration <= 2000
availability    ok / duration_pending / unavailable
```

**`domain`은 층으로 쓰지 않는다.** P2의 층은 `query type`(장면형·자막형·복합형)이고
(보충2 §2-1), `domain`은 기록·기술용이다. 도메인으로 층을 만들면 층이 두 축으로
늘어나 셀당 표본이 무너진다.

## 3. `lecture_dialog` — **주 표집틀에서 제외한다**

```
결정   제외. 삭제하지 않고 out_of_scope로 기록한다
사유   말하는 사람만 나오는 영상은 캡션 채널이 설명할 화면 변화가 적다.
       캡션 채널의 역할 자체가 달라지므로 다른 기전이 추정치에 섞인다
```

**미학적 판단이 아니라 기전의 차이다.** P2가 재는 것은 `4B − 3B` 캡션 대비이고,
캡션이 기술할 시각 변화가 거의 없는 영상에서는 그 대비가 무엇을 재는지 달라진다.

> **부수 효과를 알고도 제외한다** — 강연 6편을 넣으면 EBS 점유율이 0.909에서
> 0.698로 떨어진다(비-EBS가 7 → 13). 집중도만 보면 넣는 것이 유리하다. 그래도
> **기전이 섞이는 쪽보다 집중도를 따로 다루는 쪽**을 택한다.

강연군이 필요하다고 판단되면 **별도 사전등록으로 별도 층**을 만든다. 주 추정치에
섞지 않는다.

## 4. EBS 집중도 상한 → `k` 상한 (숫자를 미리 낸다)

주 표집틀에 들어오는 것:

```
EBS 적격 문서물        30
비-EBS 적격 문서물     3    (kbs 2 · other 1)
기확보 FREE 4편        4    (크리에이터 콘텐츠, 이미 인덱싱됨)
비-EBS 합계            7
```

EBS 점유율 상한을 `c`로 두면 `EBS ≤ 7c/(1−c)`다.

| EBS 상한 `c` | EBS 편수 | 총 `k` | 실제 점유율 |
|---|---|---|---|
| 0.70 | 16 | **23** | 0.696 |
| 0.75 | 21 | **28** | 0.750 |
| 0.80 | 28 | **35** | 0.800 |
| 상한 없음 | 30 | **37** | 0.811 |

**따라서 이 reservoir로 도달 가능한 `k`의 최대는 37이다.**

> **`k = 53`은 현재 reservoir로 도달할 수 없다.** 12편 더 필요하고, 그것은 reservoir
> 확장이 선행이다. **`k = 16`·`24`는 도달 가능하다.**

**상한 `c`를 결과 보고 완화하지 않는다.** `c`를 정하면 그것이 `k`의 천장을 정한다.

## 5. 선택 절차 — 판단이 들어오지 않게 한다

```
1  적격 pool을 확정한다 (§0의 39건 중 주 표집틀 33 + FREE 4)
2  `c`와 `k`를 사용자 승인으로 확정하고 별도 문서로 커밋한다     ← 승인 ①
3  방송사별 쿼터를 `c`에서 계산한다
4  각 쿼터 안에서 **seed 고정 단순무작위**로 뽑는다. seed는 20260820
5  뽑힌 목록을 커밋한 뒤 인덱싱한다                              ← 승인 ②
```

**금지**

```
제목·썸네일·내용을 보고 개별 영상을 고르거나 빼는 것
"이 영상은 캡션이 잘 붙을 것 같다"는 판단
인덱싱한 뒤 캡션·점수를 보고 영상을 교체하는 것
뽑힌 영상이 마음에 안 들어 seed를 바꾸는 것
```

`availability`가 `unavailable`·`duration_pending`인 건은 pool에 넣지 않고 **개수를
보고한다.** 나중에 접근이 풀려도 이번 표집에 추가하지 않는다.

## 6. **외적 타당도 진술 — P2 결과 문서에 반드시 넣는다**

기존 dev·test는 크리에이터 채널 콘텐츠고, P2 표본은 방송사 다큐멘터리가 다수다.
**도메인 이동이 실재한다.**

> **P2의 결론은 "장편 방송 다큐 중심 표본에서 `4B − 3B` 효과의 부호"다.**
> 배포 대상 전체로 일반화하지 않는다. dev(크리에이터 콘텐츠)에서 관측된 −0.090과
> 방향이 같아도 **같은 모집단에서 재현된 것이 아니다.**

이 문장을 **결과를 본 뒤에 발견하지 않도록 지금 적는다.** 방송 다큐는 자막이 화면에
많이 박혀 있어 `자막형`·`복합형` 층과 상호작용할 여지가 크고, 부호 역전이 가장 컸던
층이 `복합형`(−0.2407)이었다.

## 7. 중복 판정 — **ID 대조가 불가능하다**

기존 11편의 `work/*/meta.json`에는 `dim`·`embed_model`·`n_segments`·`text_hash`만
있다. **출처 URL·영상 ID가 기록돼 있지 않아 ID 단위 중복 대조를 할 수 없다.**

```
현재 근거   프로그램 계열 disjointness — 방송사 프로그램과 기존 크리에이터 채널이
            서로 겹치지 않는다. `id_level_verified: false`로 산출물에 기록했다
provenance 수정  앞으로 신규 영상은 `source_url`·`source_id`를 meta에 기록한다
```

**이 공백을 "확인했다"로 쓰지 않는다.**
