# 사전등록 — 융합 feature 진단 (질의 시점 관측량이 위험 구간을 예측하는가)

**작성 2026-08-18. 데이터를 읽기 전에 작성·커밋한다.** 이 문서는 수정하지 않는다.
결과가 이 문서와 다르면 결과 쪽에 사유를 적는다.

---

## 0. 이 실험이 **아닌** 것

| | |
|---|---|
| test 접촉 | **없다.** 표본은 AI Hub `split="external"` 1,086질의다. 8회차 HOLD·test 미접촉은 그대로다 |
| 채택 판단 | **아니다.** 캡션 모델·α·τ 무엇도 이 결과로 바꾸지 않는다 |
| adaptive α 구현 | **하지 않는다.** rule 설계·α 최적화·성능 확인은 이 사이클에서 금지 |
| GPU 배치 | **아니다.** 저장된 인덱스·캡션만 쓴다. 신규 캡션 생성 0 |

**이 사이클은 진단 질문 하나만 닫는다.** 실용 질문(그 feature로 α를 바꾸면 실제
MRR이 오르는가)은 **별도 사전등록**으로 넘긴다. 같은 표본에서 AUC 임계도 고르고
rule도 고르고 성능까지 확인하면 이중 사용이다.

---

## 1. 질문

> **GT를 쓰지 않는 질의 시점 관측량만으로, 자막 단독 순위가 2~5위인 질의를
> 판별할 수 있는가?**

**왜 이 층인가.** `docs/재분석_전달분해_2026-08-17.md` §3-3에서 캡션 개선의 융합
전달률이 가장 낮은 층이 자막 단독 2~5위였다(전달률 50.4% / 44.7%, 두 arm 짝에서
공통). 1위 층·6위 이하 층은 짝에 따라 61↔84·68↔90으로 크게 흔들려 인용하지 않았다.

**이 층 경계는 사후에 정해졌다.** 원문이 그렇게 자백하고 있다("사전등록되지 않은
사후 층화이고, 층 경계도 사후에 정했다"). 따라서 이 진단은 **[2,5]가 옳은 경계임을
확증하지 않는다.** 오직 **그 층이 질의 시점에 판별 가능한가**만 묻는다.

## 2. 표본

| | |
|---|---|
| 주표본 | AI Hub `queries_aihub.jsonl` **1,086질의 · 194영상** (`split="external"`) |
| 인덱스 | 본 AI Hub 인덱스 `work_aihub/` — 저장된 `emb_sub.npy`·`emb_cap.npy` |
| 질의 임베딩 | KURE-v1 (config `embed_model`), 1,086건 신규 임베딩 |
| 캡션 재생성 | **없음** |

**표본 재사용을 명시한다.** 이 1,086질의는 모델 확증과 2×2에 이미 썼다. 다만 이번
estimand는 **arm 비교가 아니라 arm 내부의 구조적 성질**이고, 목표변수는 자막 채널만
쓰므로 캡션 arm 선택과 독립이다. 그래도 결과는 **선택·추정**으로만 읽는다.

---

## 3. 목표변수 (primary target)

```
y = 1  if  subtitle-only GT rank ∈ [2, 5]
y = 0  otherwise
```

- 자막 단독 순위 = α=1.0, 즉 `emb_sub @ q_emb` 만으로 매긴 순위.
- GT rank는 `gt_seg_idx` 중 **최상위 순위**(`m6_evaluate._rank_of`와 동일 규약).
- **목표변수는 캡션 arm과 무관하다.** 자막 채널만 쓰므로 4개 arm 어디서나 동일하다.
- 양성률은 결과에 보고한다. 사전 기대는 전달분해 §3-3의 362/1,086 ≈ 33.3%.

**전건 규칙.** 양성이 50건 미만이면 AUC 추정이 과소검정이므로, 점추정이 무엇이든
§6의 "약한 신호" 밴드로 판정한다.

---

## 4. feature — 8개 고정

**GT·정답 순위·평가지표를 입력에 넣지 않는다.** 전부 질의 시점에 계산 가능하다.

| # | 이름 | 정의 |
|---|---|---|
| 1 | `sub_top1_score` | 자막 채널 최고 코사인 |
| 2 | `sub_top2_score` | 자막 채널 2위 코사인 |
| 3 | `sub_top1_minus_top2` | 1 − 2 |
| 4 | `sub_top1_minus_top5` | 자막 1위 − 5위 |
| 5 | `cap_top1_score` | 캡션 채널 최고 코사인 |
| 6 | `cap_top1_minus_top2` | 캡션 1위 − 2위 |
| 7 | `sub_cap_top1_score_gap` | `sub_top1_score − cap_top1_score` |
| 8 | `sub_cap_top1_same_segment` | 두 채널 top1 구간이 같으면 1, 아니면 0 |

**척도 고정: raw 코사인.** z-score는 융합 단계의 정규화이고, 질의별 표준편차로
나눈 격차는 **다른 feature**다. z 변형은 §8 탐색으로 분리한다.

**금지.** 결과를 본 뒤 feature를 추가·변형·조합하지 않는다. 추가하면 그 분석은
전부 탐색으로 표기한다.

## 5. 모델·교차검증

| | |
|---|---|
| 모델 | 로지스틱 회귀, L2, 표준화(fold 내 fit) |
| 교차검증 | `GroupKFold(groups=video_id)`, **k=5** |
| 주지표 | **out-of-fold AUC** (전체 OOF 예측을 한 번에 집계) |
| 불확실성 | **영상 클러스터 부트스트랩** 95% CI, B=2000, seed=`config.seed` |
| 단변량 | feature 8개 각각의 단변량 AUC도 보고(적합 없음, 누출 없음) |

**영상 단위로 묶는다.** 같은 영상의 질의가 train·test fold에 동시에 들어가면
분류기가 영상 특성을 외운다. 부트스트랩도 같은 이유로 영상 단위 재표집이다.

---

## 6. 판정 기준 — **결과를 보기 전에 고정**

판정은 **점추정이 아니라 OOF AUC의 영상 클러스터 95% CI 하한**으로 한다.

| CI 하한 | 판정 | 다음 |
|---|---|---|
| **< 0.60** | **신호 없음** | adaptive α는 구현 불가로 종결. 이것 자체가 결과다 |
| **0.60 ~ 0.70** | **약한 신호** | rule을 만들지 않는다. 표본·feature 확장 후 다음 사이클 재판정 |
| **≥ 0.70** | **신호 있음** | **별도 사전등록**으로 adaptive α rule 설계 착수 |

**이 사이클에서 rule을 만드는 경우는 없다.** 셋 중 어느 밴드든 산출물은 진단
보고서다.

## 8. 부수·탐색 분석 (판정에 쓰지 않는다)

전부 **탐색**으로 표기하고 §6 판정에 반영하지 않는다.

1. **arm 강건성** — 캡션 채널 feature(5~8)를 2×2의 `qwen3vl_4b/P0` 캡션으로
   교체해 같은 절차. 캡션 모델이 바뀌어도 답이 유지되는가.
2. **대안 목표변수** — `adaptive_helpful` = α를 0.5→0.3으로 내렸을 때 융합 rank가
   개선되는 질의. 더 직접적이지만 사후 정의라 부수로 둔다.
3. **z 정규화 변형** — 격차 feature를 질의별 z-score로.
4. **질의 유형별** — AI Hub `type` 라벨별 양성률·AUC.
5. **dev 96 전이** — 같은 절차를 dev에 적용. 표본이 작아 참고만.
