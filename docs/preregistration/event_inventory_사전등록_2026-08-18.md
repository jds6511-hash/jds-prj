# 사전등록 — 정답 사건 목록(event inventory) 작성 규격

**작성 2026-08-18. 목록을 한 건도 쓰기 전에 작성·커밋한다.** 이 문서는 수정하지 않는다.
근거: `M8_event지표_보충_2026-08-18.md` §3 — 계산 규칙은 이미 고정됐고, 여기서는
그 규칙이 먹을 **분모**를 정의한다.

---

## 0. 가장 중요한 규칙

> **정답 사건 목록은 M8·M9 출력과 독립적으로 작성한다. 해당 영상의 M8 출력은
> inventory 동결 전에 열람하지 않는다.**

사람이 M8이 제안한 사건 단위를 먼저 보면 **무엇을 하나의 사건으로 셀지**가 그쪽으로
끌려간다. 그러면 Hungarian 매칭을 아무리 잘 정의해도 분모가 이미 오염돼 있다.
검색 라벨의 "결과를 보고 고르면 선정 자체가 오염" 규칙과 같은 계열이다.

**동결을 코드로 강제한다.** `event_inventory_kit.py --freeze`가 목록 해시·git
HEAD·시각을 기록하고, 그 파일이 없으면 분석 도구가 목록을 읽지 않는다.

---

## 1. 무엇을 보고 쓰는가

| 보이는 것 | 원본 영상(화면·소리), 시각, 탐색용 스토리보드(프레임+시각만) |
|---|---|
| **숨기는 것** | M8 출력·생성 캡션·STT 자막·검색 결과·기존 질의 라벨·M9 판정 |

**스토리보드는 탐색용이다.** 정지 프레임만으로는 사건 경계를 못 잡는다 — 경계는
**영상을 재생하며** 정한다. 시트는 "그 장면이 몇 분쯤인지" 찾는 용도다.

---

## 2. 사건의 단위 — **결과 보기 전에 정의한다**

이게 흔들리면 분모가 흔들린다. Hungarian·IoU 정의보다 이쪽이 더 중요하다.

```
사건 = 하나의 목적을 가진 연속된 행위·상태 변화·상호작용.

분리한다:  행위 주체가 바뀔 때
           목적이 바뀔 때 (재료 준비 → 조리)
           장소가 실질적으로 바뀔 때
병합한다:  같은 목적의 행위가 30초 이내 간격으로 이어지면 하나로 본다
분리하지 않는다:  카메라 컷·앵글 전환만으로는 나누지 않는다
                  같은 행위 중의 짧은 삽입 장면(리액션 컷 등)
제외한다:  인트로·아웃트로·협찬 고지·자막만 있는 전환 구간
```

**동시에 일어나는 별개 사건은 각각 적는다** — 겹치는 구간이 생겨도 된다.
겹침 수는 산출물에 기록하고, 그것으로 목록을 되돌리지 않는다.

**분량 목표를 두지 않는다.** "영상당 N개" 같은 목표를 주면 그 수에 맞춰 쪼개거나
합치게 된다. 규칙대로 나오는 만큼 적는다.

---

## 3. 입력 형식

영상당 CSV 한 장. **사용자는 seg 번호를 쓰지 않는다.**

```csv
start_sec,end_sec,event,unclear
0,35,현장 도착,
40,70,관계자와 대화,
75,140,묘 이장 작업,
150,158,알 수 없는 장면,1
```

| 열 | |
|---|---|
| `start_sec`·`end_sec` | **초 단위.** 소수 허용. `start < end` |
| `event` | 한 줄 이름. 서술이 아니라 **무슨 일인지**만 |
| `unclear` | 판단 불가면 `1`. **주분석에서 제외**하고 수를 보고한다 |

**seg 범위는 코드가 파생한다** — `derive_gt_seg_idx`(1초 이상 겹치는 모든 세그먼트,
없으면 최대 겹침 1개). 검색 라벨의 `gt_seg_idx` 파생과 **같은 규칙**을 쓴다.
사람이 번호를 직접 쓰면 오탈자와 규칙 이탈이 섞인다.

---

## 4. 검증 (도구가 강제)

| # | 검사 | 실패 시 |
|---|---|---|
| V1 | `start < end` | 거부 |
| V2 | `0 ≤ start`, `end ≤ 영상 길이` | 거부 |
| V3 | `event` 비어 있지 않음 | 거부 |
| V4 | 파생 span이 영상 구간 범위 안 | 거부 |
| V5 | 겹치는 사건 쌍 수 | **기록만** (동시 사건은 정상) |
| V6 | `unclear` 비율 | **기록만**, 주분석에서 제외 |

**V1~V4 중 하나라도 실패하면 동결하지 않는다.**

---

## 5. 동결과 그 뒤

```
작성 → --validate 통과 → --freeze → FROZEN_{video_id}.json
                                     (사건 목록 sha256 · git HEAD · 시각)
                          ↓
                    이 시점 이후에만 M8 출력 열람
```

**동결 후 목록을 고치면** 해시가 달라져 도구가 불일치를 보고한다. 고쳐야 할 사유가
생기면 **사유를 기록하고 새로 동결**한다 — 조용히 덮어쓰지 않는다.

이 문서가 그것을 바꾸지 않는다.

## 7. 한계 — 미리 적는다

- **작성자가 한 명이다.** 작성자 간 일치도를 잴 수 없다(원 사전등록 §5와 동일).
  두 번째 작성자가 생기면 그때 일치도를 잰다.
- 사건 경계는 초 단위 판단이라 ±수 초의 흔들림이 있다. temporal IoU가 그 흔들림에
  민감하므로, 주지표를 임계가 아닌 **연속값**으로 둔 이유가 여기에도 있다.
- 30초 병합 규칙에 외부 근거가 없다. 결과와 함께 이 사실을 병기한다.
