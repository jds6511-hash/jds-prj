# 사전등록 — AI Hub 4-arm α 곡선 (진단 전용)

**작성 2026-08-18. 곡선을 보기 전에 작성·커밋한다.** 이 문서는 수정하지 않는다.

---

## 0. 이 분석의 지위 — **채택 α를 정하지 않는다**

| | |
|---|---|
| **AI Hub optimum은 채택 α가 아니다** | 이 1,086질의는 **모델 선택에 이미 썼다**. 같은 표본에서 α까지 고르면 이중 사용이다 |
| 배포 α | **α\*=0.5 불변.** 이 분석으로 바꾸지 않는다 |
| 저장 위치 | `docs/probes/_scratch/aihub_alpha_curve_2x2.json`. **`results/alpha_search_dev.json`에 쓰지 않는다** |
| test 접촉 | 없음 |
| GPU | 저장된 9,312 캡션 재임베딩만. **VLM 생성 0** |

**이 분석이 답하는 것은 하나다 — dev에서 α를 다시 탐색할 가치가 있는가.**

α 정의는 코드가 유일한 출처다(`src/m5_search.py:39`).

```
score = α · subtitle + (1 − α) · caption
α=0.0 캡션 단독 · α=1.0 자막 단독
```

## 1. 설계

| | |
|---|---|
| arm | 2×2의 4개 — `3B/P0` `3B/P1` `4B/P0` `4B/P1` (동일 배치 생성, 전부 bf16) |
| 격자 | α = 0.0, 0.1, …, 1.0 (11점) |
| 표본 | AI Hub 1,086질의 · 194영상 (`split="external"`) |
| 자막 채널 | 본 인덱스 `emb_sub` — arm 무관 |
| 부트스트랩 | B=2000, seed=`config.seed`, **영상 클러스터** + video-macro |

## 2. α점마다 저장하는 것

```
mrr · hit@1 · hit@5 · per_query_rr
ci95_vs_best (영상 클러스터, paired-diff) · video_macro_mrr
```

곡선 수준 요약:

| 이름 | 정의 (사전 고정) |
|---|---|
| `alpha_best_point` | MRR 점추정 최대인 α |
| `tie_set` | best와의 paired-diff **영상 클러스터 CI가 0을 포함**하는 α 집합 |
| `max_neighbor_drop` | 기준 α의 양 이웃(±0.1) MRR 하락 중 최대. **α=0.5와 best 두 기준 모두** 낸다 |
| `local_maxima_count` | 양 이웃보다 높은 내부 격자점 수 |
| `plateau_width` | `max(MRR) − 0.005` 이상인 **연속** 구간의 폭(격자 수 × 0.1) |

*`max_neighbor_drop`은 8회차 A2와 같은 계산이다. 다만 **판정 게이트로 쓰지 않는다** —
8회차 A2는 dev 기준이고 여기는 AI Hub다.*

## 3. 주 질문 — 셋만

**Q1. 4B 두 arm의 곡선이 3B보다 전체적으로 위로 이동하는가.**
캡션 모델 개선이 α=0.5 한 점의 사건인지, 융합 전반에서 유지되는지.
판정: 11개 α 전부에서 `4B/P0 − 3B/P0` 부호가 양수인가, 그리고 각 점의 영상 클러스터
CI가 0을 배제하는 α가 몇 개인가.

**Q2. `4B/P0`의 optimum이 0.5에서 이동하는가.**
- 0.3~0.4 쪽으로 이동 + 안정적 plateau → **개선된 캡션 채널을 기존 α=0.5가 충분히
  활용하지 못했다**는 진단. **dev α 재탐색 가치 있음.**
- optimum이 여전히 0.5(또는 tie_set이 0.5를 포함) → **기존 α가 새 모델에 특별히
  불리하지 않았다.** α 재조정은 큰 지렛대가 아니다.

**Q3. best point가 아니라 곡선 **안정성**이 바뀌는가.**
8회차에서 문제였던 것은 최고점이 아니라 오른쪽 어깨다(A2 0.0665, 임계 0.06).
`max_neighbor_drop`·`plateau_width`·`local_maxima_count`를 함께 본다.

## 4. 해석 규칙 — 결과 보기 전에 잠근다

| 관측 | 쓸 수 있는 문장 |
|---|---|
| `4B/P0` optimum이 0.5와 다름 | **"dev 재탐색이 필요하다"까지.** "α를 바꾼다"는 금지 |
| α=0.5보다 best α에서 Δ가 **커짐** | **calibration mismatch 가능성** — 고정 α가 이득을 덜 썼다 |
| best α에서도 Δ가 거의 같음 | **"고정 α가 병목"이라는 가설이 약해진다** |
| best α에서도 Δ가 +0.02 수준 | 병목은 모델 calibration이 아니라 **포화·평가 규모** 쪽 |
| 곡선이 뾰족해지거나 neighbor drop 증가 | 성능과 **별개로 안정성 위험**으로 기록 |

**tie_set이 넓으면 optimum 이동을 주장하지 않는다.** 점추정 최대는 표집 잡음으로
쉽게 움직인다.
