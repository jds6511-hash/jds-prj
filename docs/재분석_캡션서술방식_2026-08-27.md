# Qwen2.5-VL-3B vs Qwen3-VL-4B 캡션 서술 방식 — 사후 쌍대 기술 분석 (2026-08-27)

**성능 비교가 아니다. 모델 선택 실험도 아니다.** 같은 프레임을 두 모델이 캡션에
어떻게 남겼는지를 기술한다. 새 가설검정·p-value를 만들지 않았고, 기존 2×2 성능 결론을
수정하지 않는다.

```
산출물   docs/probes/_scratch/caption_style_paired.json
코드     docs/probes/caption_style_paired.py
GPU      사용 안 함 (저장된 캡션만 읽었다)
```

| 층 | 표본 | 쌍 |
|---|---|---|
| PRIMARY | AI Hub 194편 · `3B/P0 ↔ 4B/P0` | 2,328 |
| SENSITIVITY | 같은 표본 · `3B/P1 ↔ 4B/P1` | 2,328 |
| CROSS-CHECK | dev 3편 · P0 | 655 |
| ILLUSTRATION | `pland_costco_hosting` · 동시점 생성 2 arm | 395 |

접근하지 않은 것: **M8 C2 판정 패널 8편**(라벨링 blind 유지) · 공식 test · P2/P3 자원.

---

## A. 얼마나 많이 말하는가

캡션 길이(문자) 중앙값.

| 층 | 3B | 4B | 중앙 길이차(3B−4B) |
|---|---|---|---|
| PRIMARY (P0) | **133** | 73 | +54 |
| SENSITIVITY (P1) | 82 | **97** | **−15** |
| CROSS-CHECK dev (P0) | 127 | 73 | — |
| ILLUSTRATION (P0) | 129 | 70 | — |

**길이 우열이 프롬프트에서 뒤집힌다.** P0에서는 3B가 60자 이상 길지만, P1에서는 4B가
더 길다. 따라서 **"3B가 더 자세한 모델"은 이 데이터로 말할 수 없다** — 길이는 모델
고정 특성이 아니라 모델×프롬프트 상호작용이다.

문장이 끝나지 않은 채 멈춘 캡션(절단 후보) 비율: P0에서 3B 6.6% · 4B 4.5%,
dev에서 3B 15.7% · 4B 4.4%. 공유 상한 `max_new_tokens=128`이 **3B 쪽을 더 자주 자른다.**

### 길이가 정보 증가인가, 장황함인가

| 지표(P0 중앙값) | 3B | 4B |
|---|---|---|
| 문장 수 | 3 | 1 |
| unique token 비율 | 0.93 | 1.00 |
| 반복 bigram 평균 | 0.24 | 0.01 |

3B는 같은 표현을 다시 쓰는 일이 4B보다 잦지만(평균 0.24 vs 0.01), 중앙값 기준
unique 비율 0.93은 **길이 대부분이 반복이 아니라는 뜻**이다. 즉 P0에서 3B의 길이는
주로 내용 추가지, 같은 말 반복이 아니다.

## B. 무엇을 골라서 말하는가

### 어휘 겹침이 매우 낮다

같은 프레임인데 내용어 Jaccard 중앙값이 **0.13**(P0) · 0.14(P1) · 0.11(dev·케이스
스터디)이다. 두 모델은 같은 화면을 보고 **거의 다른 단어들로** 쓴다.

### 화면 글자를 언급하는 성향 — 네 표본 전부 같은 방향

`text_reference_candidate`(따옴표 · "적혀/문구/글씨/자막/간판/표지판" · 대문자 문자열).

| 층 | 3B | 4B | 쌍대 분해 |
|---|---|---|---|
| PRIMARY | **11.1%** | 0.3% | 3B만 258 · 4B만 7 · 둘 다 1 · 없음 2,062 |
| SENSITIVITY | **11.4%** | 2.9% | 3B만 264 · 4B만 66 |
| CROSS-CHECK dev | **27.6%** | 10.2% | 3B만 133 · 4B만 19 · 둘 다 48 |
| ILLUSTRATION | **18.0%** | 2.8% | 3B만 64 · 4B만 4 |

케이스 스터디 1편에서 본 `21 vs 0`이 **194편에서도 같은 방향**으로 나왔다.
다만 이것은 **overlay 재현이 아니다** — 자동 탐지는 편집 자막과 실제 장면 글자(간판·
라벨·현수막)를 구분하지 못한다. "3B가 편집 자막을 더 읽는다"를 말하려면 검출된 차이
사례를 사람이 `editorial overlay / in-scene text / false positive`로 갈라야 한다.
후보 목록은 산출물에 저장돼 있다.

### 서술 초점·문체

한쪽에만 나온 단어 상위(P0):

```
3B만   있습니다 · 그녀 · 있으며 · 보입니다 · 입고 · 배경에 · 검은색 · 화면에 · 주변에
4B만   있다 · 식탁 · 있고 · 수많 · 울타리 · 보인다 · 빨간색 · 목재 · 플라스틱
```

두 가지가 보인다. ① **문체가 다르다** — 3B는 합쇼체(`있습니다`), 4B는 평서체(`있다`).
② 3B 쪽에 `배경에`·`화면에`·`주변에` 같은 **장면 배치 표현**이 몰려 있다. 실제로
장소·맥락 표현 수 중앙값이 P0에서 3B 3 · 4B 1이다(P1에서는 1 vs 2로 뒤집힌다).

행동 표현과 인물 표현 수는 두 모델 중앙값이 같다(각각 2, 1). 즉 **차이는 "누가 무엇을
하는가"가 아니라 그 주위를 얼마나 적느냐**에서 난다.

> POS 분석기가 이 환경에 없어(kiwipiepy·konlpy·mecab 미설치) 위 분류는 어미·조사
> 표층 휴리스틱이다. 지표가 아니라 방향 확인용이다.

## C. 출력 부작용

| 항목(P0) | 3B | 4B |
|---|---|---|
| 한자 포함 | 4.1% | **10.3%** |
| 가나 포함 | **1.9%** | 0.04% |
| 한자 포함 (P1) | 2.6% | **14.7%** |

**4B가 "간결하고 깨끗하다"는 그림은 성립하지 않는다.** 한자 혼입은 4B 쪽이 2~5배 높고,
이는 기존 2×2의 I1b 관측(4B 241·341 vs 3B 125·174)과 방향이 같다. 가나 혼입은 반대로
3B가 높다.

실제 사례에서 두 모델의 실패 양상이 다르게 나타났다.

```
3B   캡션 전체를 중국어로 생성한 사례 (pland seg125)
     프레임과 무관한 내용을 반복 서술한 사례 (pland seg332 — "노란색 수영복" 3회 반복,
     같은 프레임에서 4B는 "직조기 앞에서 천을 조정하는 노인"으로 썼다)
4B   영어 명사구를 그대로 남긴 사례 ("wooden gazebo 아래에서 책을 읽고 있는 사람")
     극단적으로 짧게 끝낸 사례 ("손으로 빗어진 천 위에 컷팅하는 모습이다")
```

## 방어 가능한 관찰

```
① 같은 프레임에서 두 모델의 내용어 겹침은 낮다 (Jaccard 중앙값 0.11~0.14)
② P0에서 3B 캡션이 더 길고 문장 수가 많다. 그 길이는 주로 반복이 아니라 내용이다
③ 길이 우열은 프롬프트에 따라 뒤집힌다 (P1에서 4B가 더 길다)
④ 화면 글자를 언급하는 캡션 비율은 네 표본 모두에서 3B가 높다
⑤ 한자 혼입은 4B가 높고 가나 혼입은 3B가 높다 — 부작용의 종류가 서로 다르다
⑥ 행동·인물 표현 수는 비슷하고, 차이는 배경·맥락 서술량에서 난다
```

## 말하면 안 되는 주장

```
✗ "3B가 더 자세한 모델이다"            길이 우열이 P1에서 뒤집힌다
✗ "4B가 더 정확하다 / 더 깨끗하다"      한자 혼입은 4B가 더 높다
✗ "194편에서 overlay 전사를 재현했다"   자동 탐지는 편집 자막과 장면 글자를 못 가른다
✗ "이 분석이 모델 채택 근거다"          사후 기술 분석이다. 2×2 사전등록 결과가 판정이다
✗ "AI Hub 194편이 대표 표본이다"        재사용 표본이다
✗ "두 모델이 서로 다른 것을 본다"        캡션에 다른 정보를 **선택해 남겼다**가 정확하다
```
