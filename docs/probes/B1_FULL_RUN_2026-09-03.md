## 5. canary 발견 ①에 대한 정정

canary(600~780초)에서 "자수 공장 화면 + 요리 발화"를 보고 **STT 내용 불일치 의심**으로
적었다. 전체 실행으로 보면 그 해석은 지지되지 않는다.

```
영상 제목       "…성심당 복숭아시루 만들기" — 일상 vlog에 제빵·요리 구간이 실제로 있다
정렬 표본       seg 33  STT "설탕 1스푼 참기름 1스푼"  / CAP 반죽을 그릇에 담는 손
               seg 387 STT "성심당 아니고 성실당 케이크 만들어서…" / CAP 상자에서 제품 꺼냄
               seg 339 STT "설탕 당근 마늘 다진마늘"     / CAP 주방·믹서·유리잔
결론           요리 어휘는 영상의 실제 내용이다. canary 구간에서 화면(자수)과 발화(요리)가
               어긋나 보인 것은 **구간 국소 현상**이고, 그 문구는 전체에서 0회다
```

남는 것은 도메인 불일치가 아니라 **개별 전사 잡음**이다.

```
"이생 pierws 시킬 드디어" · "뼈가 터진 뼈가 vrij기장"(canary) · "탈락"
→ 라틴 문자 혼입·단어 붕괴. 정량 판정은 GT 없이는 하지 않는다
```
