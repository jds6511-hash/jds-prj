사실만 관측됐다. 블록 2개로 order effect 없음을 주장하지 않는다. 40장은 통계적 모집단
추정이 아니라 배포 운영 가능성의 descriptive measurement다.

판정 기록 `p3_opcost_verdict.json`)**: **1번 분기** — "6GB에서 안정적으로 fit +
throughput이 3B와 비슷하거나 빠름".

**읽는 문구를 정확히 쓴다 — deployment blocker는 관측되지 않았고, resource-footprint
penalty는 관측됐다.** throughput penalty·OOM은 없지만(오히려 wall-clock이 짧다)
**VRAM reserved +0.431GB · 생성 중 headroom 약 0.45GB 감소 · 저장 +1.28GB**라는 비용은
분명히 있다. "추가 operational penalty가 관측되지 않았다"고 쓰면 footprint 비용을
지운다. 운영 프로필은 여기서 **닫는다**(온도·전력·클럭 추가 없음).

동결 규칙에 따른 귀결: **최소 가치 효과를 작게 잡을 근거가 된다 → 필요한 precision이

이 측정이 답하지 않은 것: 3B vs 4B 검색 우열(dev −0.0903 ↔ AI Hub +0.0310 부호 역전

### 7-1. QC blindness 경계 수정 — "프레임만"이 아니라 "원본 source evidence만"

앞선 명세의 **"표본 감사는 프레임 실물로만"은 틀렸다.** 장면형에는 성립하지만
자막형·복합형에는 부족하다 — annotator가 원본 음성을 듣고 `gt_start/end`를 정했는데 QC
reviewer가 프레임만 보면 그 라벨이 실제 발화와 맞는지 검증할 방법이 없다.

```
장면형        원본 영상 + 프레임으로 audit 가능
자막형·복합형   원본 영상 + **원본 음성 필수**
공통 금지      모델 캡션 · 파이프라인 STT · retrieval 결과·순위·점수 · arm 정체성
```

**누출 경계는 "원본이냐 파이프라인 산출물이냐"이고 "영상이냐 음성이냐"가 아니다.**
원본 음성은 annotator가 이미 받는 입력이고 파이프라인 STT는 계속 금지다. 이 수정은
모델 결과 누출을 늘리지 않고 GT validation을 가능하게 한다. CLAUDE.md 규칙 3의
"프레임 실물 검증으로만"은 **내부 라벨 도구의 제약**이며 목적은 파이프라인 산출물
차단이다 — P3-A는 자막형·복합형을 포함하므로 원본 오디오가 GT 근거에 들어가고, 이
차이를 사전등록 동결 시 명시한다.

### 7-2. 파일럿 사양 동결 — 10 영상 × 5 질의 = 50 GT 행

정밀 추정이 아니라 **annotation logistics feasibility** 측정이다. 세 유형을 전부
작업시켜 평균 하나가 아니라 분포를 본다. 파일럿 영상은 P3 300편에 **재사용 금지**.

```
기록          총 작업시간 · minutes/row(median·p75·p90) · 유형별 시간 ·
             manual replay·난이도 · 제출 오류율 · adjudication 필요율 ·
             annotator 질문·규약 애매함 · 영상당 turnaround · 중단·실패
중복 라벨      50행의 20%(10행) 2인 독립, 세 유형 분산.
             일치도는 logistics·QC 진단 전용 — PRIMARY inclusion·weighting에 안 쓴다
판단          "1,500행 수행 가능한가?" 하나
금지          시간이 길다고 1,500 → 500으로 줄이는 것.
             그때는 P3-A 실행 자체를 다시 HOLD한다
```

### 7-3. 외부 반출 권한 감사 — 실행 완료, 반출은 HOLD

`scripts/p3_rights_audit.py`(테스트 24건) → `docs/P3_반출권한감사_2026-08-24.json`.
레지스트리를 **read-only 투영**으로만 읽고 writer가 없다(SoT 전환 계속 HOLD).

```
현재 결과   35편 전부 unclear · yes 0 · no 0 · 반출 가능 0편
          근거 파일(planning/rights_clearance.json) 없음 — 정상 초기 상태
          기확보 4편도 unclear (취득 시점 출처 기록 없음 → 보유 권한을 추정하지 않는다)
영상별 항목  external_annotation_allowed(yes/no/unclear) · 근거 ·
          제3자 제공 권한 · 보존·재배포 제한 · 작업 후 삭제 요구 · 개인 식별 추가 제약
fail-closed  기본값 unclear · unclear는 반출 불가 · 6개 항목 전부 기록돼야 yes ·
          제3자 제공 권한이 no면 즉시 no · publisher·source_url로 유추 금지 ·
          근거 파일의 미지 source_id는 오류(오타 방지)
파일럿 게이트  파일럿 영상 **전부** yes일 때만 반출 시작
```

**NDA·외주계약은 rights clearance를 대신하지 못한다** — 계약을 맺어도 원래 없던 콘텐츠
이용권이 새로 생기지 않는다. **다운로드 불가 VDI·원격 annotation 환경**을 후보로 두되,
원격 제3자 열람 자체의 허용 여부도 source terms 확인 대상이고 VDI가 clearance를
우회하지 않는다(`vdi_alternative.bypasses_rights_clearance: false`).

이 도구는 상태를 기록할 뿐 **적법성을 판단하지 않는다.** P3 신규 300편은 아직 수집하지
않았으므로 감사 대상에 없고, 파일럿 후보 영상도 선정 후 같은 절차로 감사한다.
