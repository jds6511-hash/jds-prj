### 실행 상태

- **Phase 1a (zeroth)**: 완료했으나 **무효**. arm B가 Zeroth로 파인튜닝됐고 자체
  val/test를 원본 test 50/50 분할로 만들었다고 모델카드에 명시 → arm B 누수.
  (측정 CER 0.0189 vs 모델카드 보고 2.06% 일치로 확인). 누수 사례 기록으로만 보존.
- **Phase 1b (fleurs)**: **완료**. `google/fleurs:ko_kr` test 200발화, arm B 학습셋과 무관.
  결과: `docs/probes/_scratch/stt_fleurs_compare.json`.

  | arm | 모델 | cer_numfree | cer_raw | wer_raw | 발화당 |
  |---|---|---|---|---|---|
  | A | large-v3 (현행) | 0.0497 | 0.0508 | 0.1337 | 0.98초 |
  | B | ghost613 ko-turbo | 0.0831 | 0.1004 | 0.2671 | 7.56초 |
  | C | Qwen3-ASR-1.7B-hf | 0.0445 | 0.0478 | 0.1193 | 89.97초 |

  - **arm B 유의하게 악화**: delta +0.0334, CI [0.0264, 0.0406]. Zeroth에서 "압승"으로
    보였던 것이 완전히 역전 → **누수였음이 확정**됐다.
  - **arm C 유의하지만 미미**: delta −0.0052, CI [−0.0100, −0.0009](numfree). `cer_raw`
    기준으로는 **비유의**(CI [−0.0082, 0.0015]). 중앙값은 A 0.0196 vs C 0.0182로 동급.
  - **arm C 속도가 실사용 차단 요인**: A 대비 92배 느리다. 12.5초 오디오에 90초 =
    실시간의 7배. 110분 회의면 약 13시간. 단 arm C는 eager transformers·fp16·배치1·
    flash-attn 없음이고 arm A는 CTranslate2(최적화됨)라 **구현 격차이지 구조적 한계는
    아니다** — 배치·vLLM·flash-attn으로 줄일 여지가 있으나 공짜는 아니다.
  - 품질 차이가 드러난 지점(회의록 용도 직결): 고유명사에서 C가 우세
    (C `키르치네르`·`가문비나무`·`국립 공원` vs A `히르치네르`·`가뭄비나무`·`공립공원`).
    또 **arm A가 `"자막 제공 배달의민족"` 환각을 생성**했다(Whisper의 알려진 한국어
    자막 학습데이터 오염 패턴). arm C는 없었다.

  **전면교체 판단: 아직 근거 부족.** 사용자 기준은 "유의미한 성능향상이 있다면 전면교체"
  인데, C의 개선은 통계적으로만 유의하고 실질 크기가 0.5%p이며 `cer_raw`로는 비유의인데
  92배 느리다. 반면 고유명사·환각 관찰은 **회의 도메인에서 격차가 더 클 가능성**을
  시사하므로, 교체 판단은 Phase 2(도메인 직결·누수 불가) 결과를 보고 내린다.

### 환경 제약 (Windows)

- `torchcodec` **제거 상태로 유지**. 설치하면 `backend="auto"`가 그걸 우선 선택하는데
  FFmpeg 공유 라이브러리가 없어 `libtorchcodec_core{4..8}.dll` 로드가 전부 실패한다.
  제거하면 librosa로 정상 폴백. `datasets`도 `Audio(decode=False)`+soundfile로 우회.
- `.venv_qwen3asr` = Qwen3-ASR 전용 격리 venv(transformers 5.14.1).
  **시스템 transformers는 5.9.0 그대로 유지** — 올리면 Qwen2.5-VL 캡션 출력이 바뀌어
  확정 인덱스 재현성이 깨질 수 있다.
- Qwen3-ASR 호출: `apply_transcription_request(audio=np배열, language="ko",
  processor_kwargs={"pad_to_multiple_of":100})`. 인코더가 feature length를 100프레임
  배수로 요구하고, `**kwargs`로 주면 무시된다(경고 확인). 출력 접두
  `language Korean<asr_text>`는 파싱으로 벗긴다.

## 3. 전면교체 시 주의

STT 교체는 **확정 config 변경**이다. `subtitle`이 바뀌면 `text_hash` 불일치로 M5가
`ValueError`로 막고, 재임베딩+test 재평가가 필요하다(CLAUDE.md 절대규칙 1 — dev 완료 후
사용자 승인). 또한 기존 7영상에 M1 `--force`를 쓰면 `audio.wav` mtime이 바뀌어 STT
캐시가 무효화되고 재전사되므로 **금지**.

*Whisper 전사는 완전 결정적이지 않다: `temperature` 기본값이 fallback 리스트
`[0.0, 0.2, ..., 1.0]`이라 임계값 미달 구간은 샘플링으로 재시도된다. 평소에는
`stt_cache.json`이 재전사를 막아 결과가 고정된다.*
